I don't think "Styles" is a suitable name for the whole section, so I renamed it "My Voice", which is more apt for all the functions available inside it. I also felt code-switching shouldn't be common across all the styles in the section, so I kept it inside each one. And if we want something that lets us move along our own slang or make it polished, I added the "be you" section with varying levels of polish. If we want people to experience Kivi before the output, it's better to have an experience section already there. I combined all these ideas and made my prototype.

Coming to the design, I thought orange was a more suitable colour than green because of its contrast and warmth. Nowadays, rounder-cornered toolbars are the new normal for every upcoming application, and I thought, why not, so I tried to make the left toolbar a little more so. I also chose the Garet font instead of the regular Switzer used in the app, because its more rounded text felt more natural and modern.
